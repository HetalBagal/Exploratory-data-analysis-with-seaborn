# 📊 Seaborn Data Visualization Project

This project demonstrates basic to advanced data visualization using **Seaborn**, **Matplotlib**, and **Pandas** in Python. It includes different types of plots for exploratory data analysis (EDA).

## 📁 Dataset Used
- Built-in Seaborn dataset: `tips`
- Custom dataset: `sales_data.csv`

## 🔧 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📌 Features / Visualizations

### 1. Scatter Plot
- Shows relationship between **Total Bill** and **Tip**

### 2. Line Plot
- Displays trend of **Total Bill based on group size**

### 3. Bar Plot
- Total bill comparison across different **days**
- Sales comparison by **Customer ID** and **Product Category**

### 4. Box Plot
- Shows distribution and outliers of total bill by day

### 5. Violin Plot
- Combines box plot and KDE for deeper distribution insight

### 6. Histogram
- Frequency distribution of total bill

### 7. KDE Plot
- Smooth density curve for total bill

### 8. Pair Plot
- Shows pairwise relationships between all numerical columns

### 9. Heatmap
- Correlation matrix between:
  - Total Bill
  - Tip
  - Size
